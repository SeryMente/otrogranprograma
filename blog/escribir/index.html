ESPACIO DEL AUTOR

Una nueva entrada.

Escribe, revisa y decide qué hacer público.

Este editor no inicia sesión ni publica por sí solo. El texto no sale de este navegador hasta que lo envías a GitHub. En un equipo compartido no actives el guardado local. Descarga una copia. La publicación solo ocurre cuando confirmas el cambio con tu cuenta autorizada en GitHub.

Importa un texto seleccionado de Khora, no tu archivo completo. La importación nunca publica automáticamente. No se leen otras notas ni se solicitan credenciales.

Cómo publicar y cómo conectar Khora

1. Escribe aquí o importa un texto elegido de Khora. Revisa y aprueba la versión pública.

2. Continúa a GitHub. Inicia sesión con una cuenta con permiso sobre SeryMente/otrogranprograma y confirma el archivo en main. Para textos largos se descarga un JSON: súbelo en la pantalla que se abre y confirma el cambio.

3. El despliegue construye la entrada pública. Espera su finalización y vuelve a la bitácora. Si falla, el último sitio válido sigue disponible.

También puedes indicar a Samantha el volcado concreto de Khora y revisar aquí su propuesta antes de autorizar la publicación. Esta versión es un puente editorial asistido/importación local: no es una sincronización automática ni modifica Khora.

Editar o retirar: cambia o elimina el JSON correspondiente en blog/entries/ y confirma. El historial de GitHub y las copias de terceros pueden conservar versiones antiguas; retirar la página no garantiza borrado total.
